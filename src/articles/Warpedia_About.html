Warpedia is a personal, non-commercial encyclopedia of the Warhammer 40,000 setting, written to read like Wikipedia: a neutral tone, a lead that summarises the article, an infobox, sections, footnotes and links between articles.

It exists because the usual fan wikis are hard to read: cluttered with adverts, inconsistent in tone, and organised around the game more than the lore. Warpedia keeps one layout everywhere and links every topic to the next.

How the site works

  • Every article is one HTML file in src/articles/ in the source repository. A small Python script turns them into this site and GitHub Pages serves it.
  • Blue links lead to written articles. Red links lead to topics that do not have an article yet; the Contents page lists the most wanted ones.
  • Hover a blue link to preview the article, or a footnote number to read the source without scrolling.
  • The Appearance menu changes text size, page width and light or dark colour. Your choice is kept in this browser.

Sources

Articles are written from Games Workshop's published rulebooks, codexes and Black Library fiction, cited in each article's References section. In-universe accounts often contradict each other; where they do, Warpedia says so rather than picking one.
